## 🚀 Installation & Setup

### Prerequisites
- Node.js 18+ installed
- npm or yarn

### Steps

**1. Clone the repository:**
```bash
git clone https://github.com/Khushi288-creator/portfolio.git
cd portfolio
```

**2. Install dependencies:**
```bash
npm install
```

**3. Run development server:**
```bash
npm run dev
```

**4. Open in browser:**
http://localhost:5173

**5. Build for production:**
```bash
npm run build
```
